# Architecture Decision Records
1. **Decision**: Use Spring Boot for Backend
   - **Reason**: Robust security, excellent JPA support, enterprise-grade scalability.
2. **Decision**: Use React 19 + Vite
   - **Reason**: Fast build times, modern hooks, large ecosystem.
3. **Decision**: Use Pinecone
   - **Reason**: Easy to use managed vector database for semantic similarity checks to prevent repetitive questions.
