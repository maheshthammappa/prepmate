# Features
- **AI Question Generation**: Gemini-powered questions.
- **Resume-Based Interviews**: PDF parsing (Apache PDFBox) to generate questions.
- **AI Evaluation & Scoring**: Detailed feedback and model answers.
- **Spaced Repetition Practice**: Tracking consecutive failures and scheduling practice.
- **Mastery Tracking**: Vector DB deduplication.
- **Voice Answers**: Groq Whisper integration.
- **Ask a Doubt**: In-session AI mentor.
