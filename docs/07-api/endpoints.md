# Endpoints
### POST /api/auth/register
Registers user.
### POST /api/auth/login
Authenticates user and returns JWT.
### POST /api/interview/generate
Generates questions based on topic and style.
### POST /api/interview/generate-from-resume
Parses resume and generates questions.
### POST /api/interview/evaluate
Evaluates the session and saves it.
### GET /api/interview/history
Returns user's past sessions.
