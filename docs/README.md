# PrepMate Documentation

Welcome to the comprehensive documentation for **PrepMate — AI Interview Coach**.

**Description**: An intelligent, full-stack interview preparation platform powered by Google Gemini. Practice with tailored questions, get AI-evaluated feedback, track your weaknesses, and master your skills.

## Technology Stack
- **Backend**: Java 21, Spring Boot 4.1, PostgreSQL
- **Frontend**: React 19, Vite 8, Tailwind CSS
- **AI/External**: Google Gemini API, Pinecone Vector DB, Groq Whisper API
